# Trino 472 call flow

Source review: 2026-09-25. Target remains **Trino 472 + OSS UC v0.5.1**. These are source-derived paths, not captured POC traffic. Read with [RPC contract](RPC_MATRIX.md) and [model mapping](UC_HMS_MAPPING.md). Superset deployment versions were not supplied; its section pins a reference implementation and is not deployment certification.

## Shared path and notation

The following chains expand every shorthand used in the operation table. Calls describe possible cold-cache execution; optimizations, access-control filtering, prefixes and per-transaction/shared caches change counts and ordering. They are not a promise of one RPC per SQL statement.

```text
SQL / engine MetadataManager
  -> classloader-safe ConnectorMetadata dispatch
  -> DeltaLakeMetadata
  -> DeltaLakeMetastore (HiveMetastoreBackedDeltaLakeMetastore)
  -> HiveMetastore (CachingHiveMetastore, then BridgingHiveMetastore)
  -> ThriftMetastore (ThriftHiveMetastore)
  -> ThriftMetastoreClient (ThriftHiveMetastoreClient)
  -> generated ThriftHiveMetastore.Client, TBinaryProtocol over TSocket
  -> adapter -> UC REST
```

`DeltaLakeMetadataFactory.create` installs a per-transaction cache; `DeltaLakeMetastoreModule` also installs shared-cache wiring. The view helper uses the same cached HiveMetastore directly, bypassing DeltaLakeMetastore. [T-factory](https://github.com/trinodb/trino/blob/472/plugin/trino-delta-lake/src/main/java/io/trino/plugin/deltalake/DeltaLakeMetadataFactory.java) [T-interface](https://github.com/trinodb/trino/blob/472/plugin/trino-delta-lake/src/main/java/io/trino/plugin/deltalake/metastore/DeltaLakeMetastore.java) [T-hive](https://github.com/trinodb/trino/blob/472/lib/trino-metastore/src/main/java/io/trino/metastore/HiveMetastore.java) [T-bridge](https://github.com/trinodb/trino/blob/472/plugin/trino-hive/src/main/java/io/trino/plugin/hive/metastore/thrift/BridgingHiveMetastore.java) [T-client](https://github.com/trinodb/trino/blob/472/plugin/trino-hive/src/main/java/io/trino/plugin/hive/metastore/thrift/ThriftHiveMetastoreClient.java)

| Chain | Complete method sequence | Wire response consumed | UC API (base `/api/2.1/unity-catalog`) |
|---|---|---|---|
| S: schemas | `DeltaLakeMetadata.listSchemaNames` → `DeltaLakeMetastore.getAllDatabases` → wrapper → `HiveMetastore.getAllDatabases` → bridge → `ThriftHiveMetastore.getAllDatabases` → `ThriftHiveMetastoreClient.getAllDatabases` → **`get_all_databases`** | Non-null `list<string>` of schema names; Trino filters `sys` | `GET /schemas?catalog_name=C`, all pages |
| L: table list | `DeltaLakeMetadata.listTables` or `getRelationTypes` → `streamTables` → `DeltaLakeMetastore.getAllTables(S)` → wrapper → `HiveMetastore.getTables(S)` → bridge → `ThriftHiveMetastore.getTables(S)` → `ThriftHiveMetastoreClient.getTableMeta(S)` → **`get_table_meta(S,"*",[])`** | `list<TableMeta>` with `dbName`, `tableName`, `tableType`; optional comments affect view classification | `GET /tables?catalog_name=C&schema_name=S`, all pages, eligible external Delta tables |
| T: table lookup | `DeltaLakeMetadata.getTableHandle` → `DeltaLakeMetastore.getRawMetastoreTable` → wrapper → `HiveMetastore.getTable` → bridge → `ThriftHiveMetastore.getTable` → `ThriftHiveMetastoreClient.getTable` → **`get_table_req`** (possible **`get_table`** alternative) | `GetTableResult.table` / `Table`: names/type, non-null `sd`, `sd.cols`, `sd.serdeInfo`, `partitionKeys`, provider parameter and SerDe `path`; see full mapping | `GET /tables/C.S.T` |
| V: view probe | `DeltaLakeMetadata.getView` → `TrinoViewHiveMetastore.getView` → **direct** `HiveMetastore.getTable` → bridge → Thrift/client lookup as T | Same `Table`; `tableType`, view text, parameters and owner determine whether it is a view | Same table GET; external Delta resolves as a table, not a view |
| VL: view enumeration | `DeltaLakeMetadata.getViews` → `TrinoViewHiveMetastore.getViews/listViews` → **direct** `HiveMetastore.getTables` (and `getAllDatabases` without a schema) → bridge → L/S wire calls | `TableMeta` type/comment; no view bodies fetched when all results are external tables | Same table/schema list APIs |
| D: schema properties | `DeltaLakeMetadata.getSchemaProperties` → `DeltaLakeMetastore.getDatabase` → wrapper → `HiveMetastore.getDatabase` → bridge → `ThriftHiveMetastore.getDatabase` → client `getDatabase` → **`get_database`** | `Database` name, location, owner/type, description, parameters | `GET /schemas/C.S` |

## Operations required by the POC

Examples use Trino catalog `uc_delta`, schema `raw_bdp`, table `account_info`; configuration maps `uc_delta` to UC catalog `unity`. The example partition column `event_date` must be replaced by a real fixture column.

| # | SQL / operation | Engine and connector path | Expanded HMS/UC chains above | After catalog lookup |
|---|---|---|---|---|
| 1 | `SHOW SCHEMAS FROM uc_delta` | `ShowQueriesRewrite.visitShowSchemas` → information schema → `InformationSchemaPageSource.addSchemataRecords` → `MetadataListing.listSchemas` → `MetadataManager.listSchemaNames` → `DeltaLakeMetadata.listSchemaNames` | S | No Delta log required; engine can add built-in schemas |
| 2 | `SHOW TABLES FROM uc_delta.raw_bdp` | `visitShowTables` first calls `MetadataManager.schemaExists` → inherited `schemaExists`; rewritten table query → `addTablesRecords` → `MetadataListing.listTables` → manager → `DeltaLakeMetadata.listTables` | S then L | `LIKE` is SQL filtering; it does not require a different HMS listing RPC |
| 3 | `DESCRIBE uc_delta.raw_bdp.account_info` | SQL SHOW COLUMNS form → `visitShowColumns` → schema check, materialized-view/view probes, `getRedirectionAwareTableHandle`, `getTableMetadata`; then filtered information-schema columns query | S, V, T; filtered column path below reuses T/V | `getTableMetadata` gets columns/partitions from Delta metadata/protocol; preflight deliberately surfaces errors before tolerant column listing |
| 4 | `SHOW CREATE TABLE uc_delta.raw_bdp.account_info` | `visitShowCreate` → `showCreateTable` → view probes → manager `getRedirectionAwareTableHandle/getTableMetadata` → `DeltaLakeMetadata.getTableHandle/getTableMetadata` | V, T | SQL reconstruction uses Delta columns, log comment, constraints and table properties; location comes from T |
| 5 | `SELECT * FROM uc_delta.information_schema.schemata` | `InformationSchemaPageSource.addSchemataRecords` → MetadataListing/MetadataManager → connector `listSchemaNames` | S | No per-schema `get_database` required |
| 6 | `SELECT * FROM uc_delta.information_schema.tables WHERE table_schema='raw_bdp'` | `addTablesRecords` → `MetadataListing.getRelationTypes` → `MetadataManager.getRelationTypes` → connector `getRelationTypes/streamTables` when table type is needed; otherwise `listTables` | L; S also if schema is unbounded | Full table-name constraints can instead trigger engine table/view existence checks (T/V); no new RPC |
| 7 | `SELECT * FROM uc_delta.information_schema.columns WHERE table_schema='raw_bdp'` | `addColumnsRecords` → `MetadataListing.listTableColumns` → manager `listTableColumns` → SPI default `streamRelationColumns` → Delta `streamTableColumns`, then `getViews` | L, T per table, VL; S for unbounded schema | `TransactionLogAccess.loadSnapshot/getMetadataEntry/getProtocolEntry` supplies actual columns |
| 7a | Same, plus `AND table_name='account_info'` | Manager `listTableColumns` single-relation branch → view probe, `getRedirectionAwareTableHandle`, `getTableMetadata` | V, T | Uses table handle path, not bulk `streamTableColumns` |
| 8 | `SELECT * FROM uc_delta.raw_bdp.account_info` | `StatementAnalyzer.visitTable` → manager view/table resolution and `getTableSchema/getColumnHandles` → Delta `getTableHandle/getTableMetadata/getColumnHandles`; `TableScanStatsRule.doCalculate` → statistics; split/page-source pipeline | V/T; caches may eliminate duplicate lookups | Native Delta log → active files → native Parquet reader |
| 9 | `SELECT count(*) FROM uc_delta.raw_bdp.account_info` | Same table handle and split pipeline; `getTableStatistics` → `FileBasedTableStatisticsProvider` | V/T; **no HMS statistics RPC** | Page source can synthesize rows from file-row-count statistics when its predicates permit; otherwise read Parquet. Never count UC columns or return an adapter row count |
| 10 | `SELECT * FROM uc_delta.raw_bdp.account_info WHERE event_date=DATE '2026-09-01'` | T → `DeltaLakeMetadata.applyFilter` → `DeltaLakeSplitManager.getSplits` → `TransactionLogAccess.getActiveFiles` and `partitionMatchesPredicate` | V/T; **no HMS partition RPC** | Partition columns/values, data skipping and file selection come from Delta actions |
| 11 | Superset schema discovery | `BaseEngineSpec.get_schema_names` → SQLAlchemy inspector → `TrinoDialect.get_schema_names` → `SELECT schema_name FROM information_schema.schemata` in selected catalog | S | Same as 5 |
| 12 | Superset table discovery | `BaseEngineSpec.get_table_names` → inspector → `TrinoDialect.get_table_names` → `SELECT table_name FROM information_schema.tables WHERE table_schema=:schema AND table_type='BASE TABLE'` | L (S if required by prefix planning) | View discovery uses the same information-schema table with `table_type='VIEW'`; eligible view set is empty |
| 13 | Superset column discovery | `TrinoEngineSpec.get_columns` → inspector → `TrinoDialect.get_columns` → `has_table` query on information-schema tables, then `_get_columns` query on columns filtered by schema/table | L or V/T for existence; V/T for columns | Actual types from Delta; `NoSuchTableError` fallback calls Presto engine-spec `SHOW COLUMNS FROM`, following 3 |

## Native data path

`getTableHandle` calls `convertToDeltaMetastoreTable` and extracts `sd.serdeInfo.parameters["path"]`. It loads a snapshot, reads metadata/protocol entries, checks supported reader versions/features and column mapping, and constructs a handle. The adapter's job ends at catalog metadata. [T-wrapper](https://github.com/trinodb/trino/blob/472/plugin/trino-delta-lake/src/main/java/io/trino/plugin/deltalake/metastore/HiveMetastoreBackedDeltaLakeMetastore.java) [T-metadata](https://github.com/trinodb/trino/blob/472/plugin/trino-delta-lake/src/main/java/io/trino/plugin/deltalake/DeltaLakeMetadata.java)

`DeltaLakeSplitManager.getSplits` asks `TransactionLogAccess.getActiveFiles` for active Delta files, applies partition/file predicates, and produces splits. `DeltaLakePageSourceProvider.createPageSource` performs deletion-vector/column-mapping handling and delegates to `ParquetPageSourceFactory.createPageSource`; its row-count shortcut does not require Parquet for every `count(*)`. Statistics are file/log/extended-statistics based (`FileBasedTableStatisticsProvider`), not Hive column statistics. [T-log](https://github.com/trinodb/trino/blob/472/plugin/trino-delta-lake/src/main/java/io/trino/plugin/deltalake/transactionlog/TransactionLogAccess.java) [T-splits](https://github.com/trinodb/trino/blob/472/plugin/trino-delta-lake/src/main/java/io/trino/plugin/deltalake/DeltaLakeSplitManager.java) [T-pages](https://github.com/trinodb/trino/blob/472/plugin/trino-delta-lake/src/main/java/io/trino/plugin/deltalake/DeltaLakePageSourceProvider.java) [T-stats](https://github.com/trinodb/trino/blob/472/plugin/trino-delta-lake/src/main/java/io/trino/plugin/deltalake/statistics/FileBasedTableStatisticsProvider.java)

Optional time travel (`SELECT ... FOR VERSION AS OF N` or supported timestamp form) reuses T; `getTableHandle` passes the requested end version into snapshot loading. Certify retention/checkpoint availability separately. No adapter version parser/cache is needed. [T-metadata](https://github.com/trinodb/trino/blob/472/plugin/trino-delta-lake/src/main/java/io/trino/plugin/deltalake/DeltaLakeMetadata.java) [T-log](https://github.com/trinodb/trino/blob/472/plugin/trino-delta-lake/src/main/java/io/trino/plugin/deltalake/transactionlog/TransactionLogAccess.java)

## Error and side-effect boundaries

- `streamTableColumns` catches runtime exceptions per table and may omit columns. The manager's single-relation column-listing path also catches runtime errors. This means an adapter UC failure can appear as incomplete `information_schema.columns`; correct Thrift errors cannot change this stock Trino behavior. `DESCRIBE` has an explicit metadata preflight. [T-metadata](https://github.com/trinodb/trino/blob/472/plugin/trino-delta-lake/src/main/java/io/trino/plugin/deltalake/DeltaLakeMetadata.java) [T-manager](https://github.com/trinodb/trino/blob/472/core/trino-main/src/main/java/io/trino/metadata/MetadataManager.java) [T-show](https://github.com/trinodb/trino/blob/472/core/trino-main/src/main/java/io/trino/sql/rewrite/ShowQueriesRewrite.java)
- `MetadataManager.getRelationTypeIfExists` also converts some table-handle TrinoExceptions into no relation; a filtered information-schema table-existence probe can hide a native reader failure. Superset `has_table` results are therefore not a reliable UC health probe.
- `getTableHandle` may return no handle for unsupported Delta reader version/features. Do not misdiagnose this as UC 404. [T-metadata](https://github.com/trinodb/trino/blob/472/plugin/trino-delta-lake/src/main/java/io/trino/plugin/deltalake/DeltaLakeMetadata.java)
- Metadata read paths can enqueue a metastore write when `delta.metastore.store-table-metadata` is enabled; set it explicitly false (472 default is false). Do not synthesize Trino's cached Delta schema/version parameters. [T-config](https://github.com/trinodb/trino/blob/472/plugin/trino-delta-lake/src/main/java/io/trino/plugin/deltalake/DeltaLakeConfig.java) [T-scheduler](https://github.com/trinodb/trino/blob/472/plugin/trino-delta-lake/src/main/java/io/trino/plugin/deltalake/metastore/DeltaLakeTableMetadataScheduler.java)
- Disable Hive catalog redirection (`delta.hive-catalog-name` unset) so a non-Delta lookup cannot escape to the retired HMS catalog. HMS impersonation and HMS catalog-name options are also off/unset for the minimum contract.
